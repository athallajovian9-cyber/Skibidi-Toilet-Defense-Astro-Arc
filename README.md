# SKIBIDI TOILET DEFENSE: ASTRO ARC (ALPHA)

> **DEVELOPMENT STAGE: PRE-RELEASE ALPHA**  
> **SUPPORTED TARGET OS: WINDOWS ONLY (DirectX / Vulkan / WebGPU standalone runtime)**

High-octane 2.5D physical defense arcade game featuring the Alliance & Skibidi Truce against the Astro Toilet empire.

---

### NOTICE FOR PLAYERS & TESTERS
- **Alpha Build**: This game is actively under development. Features, ballistics, mechanics, and audio balance are subject to rapid iteration.
- **Windows Only**: Optimized and tuned specifically for Windows PC architectures with hardware acceleration. Mobile and non-Windows operating systems are not supported in this branch.

---

### Core Mechanics
- **Real-Time Physics Simulation**: Newtonian $F = ma$ momentum transfers, dismemberment debris, and aerodynamic gale-force downdrafts.
- **Einstein Relativistic Dilation**: High-speed warp charging units experience physical Lorentz length contraction and optical Doppler blueshift/redshift.
- **Schrödinger's Cat Superposition**: Quantum units exist in unobserved superposition until measurement collapses them into decayed vacuum or fortified tanks.
- **4-Player Squad Multiplayer**: Cameraman, Speakerman, TV Man, and Plungerman with dedicated role synergies and crossfire focus damage.
- **Pure UDP Low-Latency Network Pipeline**: Unbuffered 0-retransmit UDP socket stream for competitive input response.
